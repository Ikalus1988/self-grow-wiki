# FANUC System Parameters

System configuration parameters for [[fanuc-r30ib-controller]], covering $PARAM_KAREL, $SCREEN, and other system-level settings.

## Common Parameter Groups

- `$PARAM_KAREL` — Karel runtime configuration
- `$SCREEN` — Pendant screen settings
- `$Ssys` — System-level parameters
